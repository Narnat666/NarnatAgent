## 6. 与现状的差异记录（有意/无害，用户不可感知）

1. **headless 输出环境置位时机**：现状在根 `main.py` 的 headless 分支内先置位再校验 `-g`；
   新实现把参数校验放在装配之前、输出环境置位在装配第 2 步。差异仅影响"既带 `-p` 空白任务
   又带非法 `-g`"一类组合的内部顺序，输出与退出码不变。
2. **日志模块名**：现状为 `core.agent`，新实现为 `app`（日志内容非对外契约，仅调试模式下
   用户可读）。
3. **`-v` 分支不写 sys.path / 不导入 App**：现状在 `-v` 返回前不导入 App（新实现一致，
   且包级 `__init__` 额外保证"任何 import 都不加载积木"）。
4. **交互模式无控制台句柄时**：现状在 `ui.start()` 抛 `NoConsoleScreenBufferError`，
   新实现在装配第 17 步（构造 `InputSession`）抛同类异常；两路径都落在根 `main.py` 的顶层

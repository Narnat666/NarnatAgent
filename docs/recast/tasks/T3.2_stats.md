# T3.2 实施任务：stats 积木（统计与费用）

## 任务目标

Stage 2：在 `v2/narnat_agent/` 实现 `stats` 积木（用量/费用累计、成本日志 CSV 与轮转、余额查询）。

- **行为金标准**：`specs/stats/spec.md`（8 Requirement）
- **现状参照**：`narnat_agent/core/stats.py`、`billing.py` + `docs/recast/reports/R2_report_core_session.md`

## 交付物

- `v2/narnat_agent/stats/__init__.py`、`tracker.py`（用量/费用/日志）、`billing.py`（定价/费用/余额）
- `v2/tests/unit/test_stats.py`

## 实施要求

1. 对齐 spec：用量累计（含缓存命中率）、费用计算（定价表查表；未知模型零费用）、成本日志（启用开关、默认路径、字段、容量轮转 `主名→_bak.csv` 保 1 活动+1 备份、失败静默）、余额查询（bearer/x-api-key、JSONPath、失败静默、每 10 轮节奏——节奏的调用点归 app，本积木提供 `fetch_balance` 语义按 spec）。
2. 结构改进：`stats._model` 私有互摸 → 提供 `set_model()` 公开方法（design D7 明示）；`billing` 与 `stats` 职责边界清晰（纯计算 vs 状态承载）。
3. 无模块级可变状态；中文 docstring。

## 测试要求

1. spec Scenario 全覆盖（映射表）。
2. 费用计算矩阵与 `v2/tests/baseline/data/billing.json` 对照。
3. 轮转行为（写满→备份→新文件）用临时目录测试；余额查询用 mock（不联网）。

## 验收标准

1. `python -m pytest tests/unit/test_stats.py -q` 通过（cwd=v2）
2. `python tests/check_layering.py` 无违规
3. billing 基准对照通过
4. spec Scenario 映射表齐备

## 失败报告格式

①已尝试方案；②报错原文；③怀疑原因。「确认失败」是合法终点。

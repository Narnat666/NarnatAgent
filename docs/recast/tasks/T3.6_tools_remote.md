## 实施要求（高风险区：会话/线程/PTY 时序）

1. **SSH 会话**：提示符检测（严格/宽形态）、哨兵完成检测、sudo 回填、ANSI 清洗、backlog 收敛、重连——**逐行对照搬运**，只重组结构。
2. **结构改进**（design D7 明示）：20+ 处跨层直取 `SSHSession._client/_channel` 改为会话对象公开方法（`send_interrupt()`/`is_closed()`/`open_sftp()` 等）；Terminal 与 Serial 的六组重复函数（注册表/解析/status/close/cleanup/确认）抽共享实现（两族差异显式参数化）；`"__AWAIT_CONFIRM__"` 字面量用常量。
3. **明示修复项**：`工具.SSH最大会话数` 对 Serial 生效（接线；默认值场景无差异——spec 有专条）。
4. 依赖注入：terminal 与 serial 的 max_sessions 由构造传入（替换 `set_max_sessions` 类属性全局）。
5. 中文 docstring。

## 测试要求

1. spec Scenario 全覆盖（映射表）。
2. 可离线测试部分：参数契约/会话注册表状态机（无连接）/输出清洗/截断/提示符形态判定（喂构造文本）——全测。

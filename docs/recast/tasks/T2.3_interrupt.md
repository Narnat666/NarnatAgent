# T2.3 实施任务：interrupt 积木（中断总线）

## 任务目标

重构 change `recast-v2` 的 Stage 1b：在 `v2/narnat_agent/` 实现 `interrupt` 积木（中断信号总线实例：双模式状态机、订阅广播）。

- **行为金标准**：`openspec/changes/recast-v2/specs/interrupt/spec.md`
- **结构金标准**：`design.md` D5（InterruptBus 实例替换模块级全局）
- **契约**：`v2/narnat_agent/contracts/interrupt.py`（InterruptSignal 协议——先行任务产物）
- **现状参照**：`narnat_agent/core/interrupt.py` + `narnat_agent/ui/interrupt.py` + `docs/recast/reports/R6_report_ui.md`（interrupt 部分）

## 交付物

- `v2/narnat_agent/interrupt/__init__.py` — 聚合导出
- `v2/narnat_agent/interrupt/bus.py` — InterruptBus 实现（signal 语义 + 订阅）+ 按键采集器（若归本积木）
- `v2/tests/unit/test_interrupt.py` — 单元测试

## 实施要求

1. **Signal 部分（跨平台无关）**：`is_set/clear/raise_/subscribe`、双模式（运行/输入）的状态机与"模式切换时机"语义——对齐 specs/interrupt「运行/输入双模式状态机」。实例化、可注入、可单测（无 UI 依赖）。
2. **采集部分**（ESC/SIGINT 按键读取）：按 specs/interrupt「平台按键采集差异」「键盘监听生命周期」，保留现状等价行为（Windows msvcrt/conhost 轮询、POSIX termios 的等价路径——以 R6 报告描述的现状为准）。
   - 结构改进：消灭现状"三套 ESC 轮询同构不共享"的重复（R6 报告发现）——抽为统一采集器。
   - 清理现状死逻辑（`_saved_sigint` 等——若确认死码，删除并在报告注明"行为等价"证据）。
3. 中断触发→广播：订阅者（LLM 断连、进程杀树、远程中断、等待唤醒）由各自积木在构造时订阅（本任务只提供广播机制）。
4. 无模块级可变全局——一切状态在实例内。
5. 中文 docstring。

## 测试要求

1. 覆盖 spec 每个 Scenario（映射表）。
2. 纯信号/订阅/双模式可全测；按键采集部分按平台条件测试（mock）。
3. 广播测试：多订阅者顺序、异常隔离（一个订阅者异常不阻断其他——以 spec/现状语义为准）。

## 边界条款

- 只创建本积木文件与测试；不改其他文件
- 不运行 narnat；不执行 git 写操作

4. 三套轮询去重证据（报告列出旧代码三处与新实现一处的对应）

# T2.4 实施任务：messages 积木（消息存储与修复）

## 任务目标

重构 change `recast-v2` 的 Stage 1b：在 `v2/narnat_agent/` 实现 `messages` 积木（消息唯一所有者、只读视图、受控修改、repair 修复）。

- **行为金标准**：`openspec/changes/recast-v2/specs/messages/spec.md`
- **结构金标准**：`design.md` D1/D6/D7
- **现状参照**：`narnat_agent/core/message_list.py` + `core/message_manager.py`（repair 部分）+ `docs/recast/reports/R2_report_core_session.md`

## 交付物

- `v2/narnat_agent/messages/__init__.py` — 聚合导出
- `v2/narnat_agent/messages/store.py` — 消息存储（唯一所有者+视图）
- `v2/narnat_agent/messages/repair.py` 或并入 store —— repair 逻辑
- `v2/tests/unit/test_messages.py` — 单元测试

## 实施要求

1. **存储语义**（对齐 spec）：system 首条；append_user/append_assistant（含 tool_calls/thinking/thinking_signature 可选字段，None 不写入、空串合法）/append_tool_result/append_interrupted_tools；replace_all 原子替换；视图零拷贝只读（含负索引访问支持——现状 repair 用到 `view()[-1]`，按 spec 语义提供）。
2. **repair 语义**（spec 逐条）：未回复 tool_call 补 "[用户中断]"；仅当第 1 步修复且尾部为 tool 时补合成 assistant（思考模式下带非空 thinking 占位——占位常量集中定义并导出，供 llm 转换层使用）；日志行为（如保留）。
3. **结构改进**：合并现状 MessageList+MessageManager 的委托层（消除纯粹转发的包装方法）；清除 `clear_and_rebuild`/`compress_and_rebuild` 等未使用或与 replace_all 重复的接口（以报告为准，确认无消费方后删除，报告注明）。
4. 无模块级可变状态；只依赖 contracts 与标准库。
5. 中文 docstring。

## 测试要求

1. 覆盖 spec 每个 Scenario（映射表）。
2. repair 全分支：无缺陷序列（不动）、未回复工具、尾部 tool、思考模式占位、多次调用幂等。
3. 视图不可变性测试（结构上无法通过视图修改列表）。
4. 快照对照：若 baseline 有 messages 基准，编写对照；未有则跳过。

## 边界条款

- 只创建本积木文件与测试；不改其他文件
- 不运行 narnat；不执行 git 写操作

## 验收标准（可计算）

1. `python -m pytest tests/unit/test_messages.py -q` 通过（cwd=v2）
2. `python tests/check_layering.py` 对 messages 无违规
3. spec Scenario 映射表齐备
4. repair 各分支测试与 R2 报告行为描述逐条一致（报告给证据）

## 失败报告格式

①已尝试方案；②报错原文；③怀疑原因。「确认失败」是合法终点。

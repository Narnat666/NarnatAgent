# T3.10 实施任务：ui 交互层（流句柄 / 输入会话 / 命令 / headless）

## 任务目标

Stage 2：在 `v2/narnat_agent/ui/` 实现交互层其余部件：OutputSink 实现（流句柄）、输入会话（prompt_toolkit）、命令注册与 Tab 补全、动画、headless 纯文本实现。

- **行为金标准**：`specs/ui/spec.md`（输入会话/命令集与分发/Tab 补全/流式输出会话句柄协议/动画/统计栏/headless/打断提示）
- **契约**：`contracts/output.py`（OutputSink / InteractionPort / TurnStats）、`contracts/interrupt.py`
- **现状参照**：`narnat_agent/ui/ui_design.py`、`ui/session_commands.py`、`ui/headless.py` + `docs/recast/reports/R6_report_ui.md`

## 交付物

- `v2/narnat_agent/ui/stream.py` — OutputSink 实现（feed 走 renderer；notify；finish 统计栏；abort；restart_attempt；spinner 暂停/恢复计数；interrupt 模式切换）
- `v2/narnat_agent/ui/prompt.py` — 输入会话（`#` 提示符、多行、历史、Ctrl+C/EOF）
- `v2/narnat_agent/ui/commands.py` — 命令补全器（可用命令集来自注入的命令源）
- `v2/narnat_agent/ui/animator.py` — 动画（思考中/压缩/合并）
- `v2/narnat_agent/ui/headless.py` — 纯文本 OutputSink 与 InteractionPort
- `v2/tests/unit/test_ui_interaction.py`

## 实施要求

1. 流句柄按 contracts.output 的协议实现；spinner 暂停/恢复的并行计数、finish 的统计栏参数（with_stats）、abort 文案、restart_attempt 的缓冲重置语义——对齐 spec。
2. 输入/命令：Tab 补全（命令随状态变化——命令源经端口注入，不 import sessions）；分发结果为继续/跳过/退出三态（按 spec「命令集与分发语义」）。
3. 动画与统计栏：格式与开关联动逐条对齐 spec（含数值格式化）。
4. headless：纯文本、静默工具日志开关语义。
5. 不 import sessions/conversation（只经 contracts 端口）。
6. 中文 docstring。

## 测试要求

1. spec Scenario 覆盖（与 T3.9 合计覆盖 ui spec 全量；本任务负责非渲染面）。
2. 可测部分：统计栏格式化（纯函数）、命令集过滤、headless sink 输出、流句柄的 pause/resume 计数、abort/finish 顺序。
3. 交互路径（真终端）无法自动化的：列明并标注「未验证」。

## 验收标准

1. `python -m pytest tests/unit/test_ui_interaction.py -q` 通过（cwd=v2）
2. `python tests/check_layering.py` 对 ui 无违规
3. spec Scenario 映射表齐备（标注与 T3.9 的覆盖分界）
4. 统计栏格式与 spec 逐字一致（报告证据）

## 失败报告格式

①已尝试方案；②报错原文；③怀疑原因。「确认失败」是合法终点。

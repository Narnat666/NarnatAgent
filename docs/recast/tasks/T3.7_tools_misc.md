3. **GoalComplete**：目标模式动态注入/移除（经 registry 的 `set_goal_tool` 等价机制）、完成标记（GoalState）、调用时后台清理、主循环消费语义——对齐 spec。
4. 无模块级可变状态；中文 docstring。

## 测试要求

1. spec Scenario 全覆盖（两 spec 合并映射表）。
2. WebSearch 用 mock（不联网）；TodoWrite 状态同步断言 PlanTracker 与通知回调；GoalComplete 标记置位/消费。

## 验收标准

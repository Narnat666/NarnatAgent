# T4.2 实施任务：sessions 积木（会话状态机 / 持久化 / 命令）

## 任务目标

Stage 3：在 `v2/narnat_agent/sessions/` 实现会话域（三态状态机、持久化、探索分支、命令实现）。

- **行为金标准**：`specs/sessions/spec.md`（17 Requirement / 70 场景）
- **契约**：`contracts/`（Tool/output 端口等按需）
- **依赖积木**：messages、compression（/compact 委托）、config（skill_store）、stats（模型切换同步经 stats.set_model）
- **现状参照**：`narnat_agent/core/session_callbacks.py`（902 行）、`config/session_store.py`（363 行）+ `docs/recast/reports/R2_report_core_session.md`、`R7_report_config.md`

## 交付物

- `v2/narnat_agent/sessions/__init__.py`、`state.py`（三态状态机）、`store.py`（持久化：保存/加载/删除/树形格式化——从旧 config/session_store.py 搬运行为，对齐 session_store 基准）、`commands.py`（全部命令实现与可用性表）
- `v2/tests/unit/test_sessions.py`

## 实施要求

1. **状态机**：NoSession/RootSession/ChildSession 的可用命令集与状态迁移、持久化时机（auto_save/exit/enter）、`/done` 的增量合并（memory/target 分界、轮次号、多轮合并、reset_after_compact）——逐条对齐 spec。
2. **持久化**：文件布局与命名、原子写、surrogate 清洗、树形/摘要格式化文本（与 `v2/tests/baseline/data/session_store.json` 对照）、删除标记与退出清理。
3. **命令**：/save /ls /cd /rm /explore /done /skill /thinking /thinkback /mode /goal /compact /exit 的行为、文案、返回值语义（继续/退出）；命令分发结果按 spec。
4. **结构改进**：902 行巨型类拆分为状态机（states）+ 命令层（commands）+ 服务层（manager）；`_goal_enabled/_goal_max_rounds` 私有互摸改为公开目标模式 API（conversation 消费）；`compact_func` 后置赋值改构造注入；`stats._model` 互摸改 `stats.set_model()`；思考/模型读写配置的 lambda 对改为注入的配置句柄（显式小对象，如 `ModelState`）。
5. 无模块级可变状态；中文 docstring。

## 测试要求

1. spec Scenario 全覆盖（映射表）。
2. 状态迁移矩阵（每态每命令的可用性/效果）、/done 合并序列、树形文本对照基准、删除标记清理。
3. summarizer（LLM 命名/总结）用 fake 注入。

## 验收标准

1. `python -m pytest tests/unit/test_sessions.py -q` 通过（cwd=v2）

4. session_store 基准对照通过

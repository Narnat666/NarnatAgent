# T3.5 实施任务：tools/shell 工具族（Shell + background）

## 任务目标

Stage 2：在 `v2/narnat_agent/tools/shell/` 实现 Shell 工具与后台任务机制。

- **行为金标准**：`specs/tools-shell/spec.md`（16 Requirement / 88 场景）
- **契约与框架**：`contracts/tool.py` + `tools/signal.py`/`registry.py`/`env.py`（T3.3 产物）
- **现状参照**：`narnat_agent/tools/bash/__init__.py`（1088 行）、`tools/background/__init__.py`（702 行）+ `docs/recast/reports/R3_report_tools_bash_bg.md`

## 交付物

- `v2/narnat_agent/tools/shell/__init__.py`、`executor.py`（bash 主体）、`background.py`（后台槽位）
- 过程互引：`BashRuntime`/`_kill_proc_tree` 的跨模块私有依赖改为显式共享（如 `process.py` 提供杀树原语，双方 import）
- `v2/tests/unit/test_tools_shell.py`

## 实施要求（高风险区：线程/进程时序保守搬运）

1. **信号与后台**：标签协议用 `tools/signal`（字面量 `__AWAIT_CONFIRM__` 用 contracts/工具常量，消灭双轨）；后台槽位、进程隔离、输出落盘/归档、wait/status/cancel 语义逐条对齐 spec。
2. **执行器**：平台自适应、cd 持久化、多段执行、python 直执行、输出解码/截断、杀进程树——**逐行对照搬运**，只重组结构（Windows/Unix 双路径保持；中断清零惯例保留但收进对象内）。
3. **结构改进**：bash↔background 的私有互引（`_kill_proc_tree`、`BashRuntime`）改为共享模块显式接口；`BashRuntime.interrupted` 跨模块读写改为显式对象/回调（语义等价）。
4. `Tool` 协议实现；`execute` 的确认挂起流程按 contracts 的 DeleteGate/ToolResult.await_confirm 设计。
5. 中文 docstring。

## 测试要求

1. spec Scenario 全覆盖（映射表）。
2. 安全可测部分必须全测：参数归一化/校验文案、分段逻辑、截断、`>nul`/重定向解析、python 直执行命中条件（mock which）。
3. 真执行路径（进程/超时/中断）用受控子命令测试（如 `echo`、ping 类短命令、可控 sleep），避免副作用；后台机制用临时目录测试。
4. 无法自动化项（真时序/ctrl 事件）列明并标注「未验证」。

## 验收标准

1. `python -m pytest tests/unit/test_tools_shell.py -q` 通过（cwd=v2）
2. `python tests/check_layering.py` 对 tools 无新增违规
3. spec Scenario 映射表齐备
4. 结果文案抽查（退出码行/中断/超时/跳过）与 spec 逐字一致（报告证据）

## 失败报告格式

①已尝试方案；②报错原文；③怀疑原因。「确认失败」是合法终点。

# T3.4 实施任务：tools/file 工具族（Read/Glob/Grep/Edit/Write）

## 任务目标

Stage 2：在 `v2/narnat_agent/tools/file/` 实现 5 个文件类工具（含各自 definition/execute，按 contracts.Tool 协议）。

- **行为金标准**：`specs/tools-file/spec.md`（25 Requirement / 97 场景）
- **契约与框架**：`contracts/tool.py` + `tools/signal.py`/`registry.py`/`env.py`（T3.3 产物）
- **现状参照**：`narnat_agent/tools/{read,glob,grep,edit,write}/`、`diff_utils.py`、`token_estimate.py` + `docs/recast/reports/R5_report_tools_file_base.md`

## 交付物

- `v2/narnat_agent/tools/file/__init__.py`、`read.py`、`glob.py`、`grep.py`、`edit.py`、`write.py`（或等价切分）
- `v2/tests/unit/test_tools_file.py`

## 实施要求

1. **行为逐条对齐 spec**（工具名/参数名/默认值/输出格式/错误文案/截断/编码/忽略目录/多路径/head_limit 降级/唯一性校验/diff）。
2. **算法搬运优先**：编码识别、花括号展开、正则搜索输出格式、行号截断——从旧实现逐行对照搬运，只重组结构。
3. 工具实现遵循 `Tool` 协议：`definition()` 返回完整 dict（与旧 DEFINITION 逐字节等价）；`execute(args, env)` 返回 `ToolResult`。
4. 依赖：`tools/signal`（标签）、`tools/env`（ToolEnv）、`token_estimate`（若归本族）——不用 contracts 之外的跨积木依赖。
5. 中文 docstring。

## 测试要求

1. spec Scenario 全覆盖（映射表；≥90 用例）。
2. 参数契约测试：每个工具的参数名/默认值/必填性（与 spec 参数表逐字）。
3. 行为测试用临时目录（读/写/编辑/glob/grep 的真实文件交互）。
4. 截断/续读提示、忽略目录过滤、编码回退（GBK）等边界。

## 验收标准

1. `python -m pytest tests/unit/test_tools_file.py -q` 通过（cwd=v2）
2. `python tests/check_layering.py` 对 tools 无新增违规
3. spec Scenario 映射表齐备
4. 五个工具 definition 与旧包 DEFINITION 逐字节比对一致（报告给证据）

## 失败报告格式

①已尝试方案；②报错原文；③怀疑原因。「确认失败」是合法终点。

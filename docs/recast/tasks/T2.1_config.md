# T2.1 实施任务：config 积木（配置加载）

## 任务目标

重构 change `recast-v2` 的 Stage 1b：在 `v2/narnat_agent/` 实现 `config` 积木（配置加载：narnat.json/narnat.md/skills 解析、默认值中心、路径查找、系统提示词拼接）。

- **行为金标准**：`openspec/changes/recast-v2/specs/config/spec.md`（逐条对照，含兼容怪癖）
- **结构金标准**：`openspec/changes/recast-v2/design.md`（D1 积木化 / D6 状态归主 / D7 无私有互摸 / D11 兼容策略）
- **现状参照**（可读不可改）：`narnat_agent/config/`（旧实现）+ `docs/recast/reports/R7_report_config.md`（行为与契约清单）

## 交付物

- `v2/narnat_agent/config/__init__.py` — 聚合导出
- `v2/narnat_agent/config/defaults.py` — 全部默认常量、prompt 模板、thinking 映射表（逐项搬运，值不得变）
- `v2/narnat_agent/config/loader.py` — 加载主流程（目录发现→生成默认文件→解析→组装配置树）
- `v2/narnat_agent/config/skill_store.py` — 技能加载（系统技能/项目技能发现/路径安全）
- `v2/tests/unit/test_config.py` — 单元测试

## 实施要求

1. 配置树结构可按积木思想重新裁剪（如拆为独立小模块），但**外部行为面**（键名解析、默认值、容错、副作用）逐项对齐 spec。
2. 彻底去掉现状已知结构问题（R7 报告"补丁痕迹"）：`AIConfig` 二次重建补 retry_count、解析风格双轨（部分裸 int()/bool()）、硬编码默认值多处重复（收敛到 defaults.py 单点）、`shell_name` 死参数（模板无占位则去掉）、模块内映射表每次调用重建（改为模块级常量）。
3. 解析风格**保持行为等价**（spec 的"兼容性怪癖保持"章节）：哪些键裸转型（会抛错）、哪些容错回落——逐一按 spec 复刻，不要"顺手修正"。
4. 无模块级可变状态；无跨模块私有访问；只依赖 contracts 与标准库（如需要 typing）。
5. 中文 docstring；每个函数注明对应的 spec 行为点。

## 测试要求

1. 单元测试覆盖 spec 的**每个 Scenario**（一一映射，在报告里给出映射表）。
2. 风险重点：目录发现优先级（NARNAT_HOME/exe/cwd 向上 10 层）、首次生成文件、键别名、单位换算（KB×1024、MB×1024²、"10k"）、容错矩阵、headless 剥离、MCP 参数解析（中英键/数组归一/字符串布尔）。
3. 若 `v2/tests/baseline/data/` 已有 config 相关基准（由并行任务生成），编写对照测试逐项比对；未有则跳过（不阻塞）。

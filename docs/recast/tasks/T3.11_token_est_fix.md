# T3.11 修正任务：token 估算唯一化（消除同名同逻辑双实现）

## 背景（架构审计结论）

`v2/narnat_agent/tools/token_estimate.py` 与 `v2/narnat_agent/compression/compressor.py` 各自实现了一份**同名同逻辑**的 `estimate_text_tokens` / `estimate_message_tokens`（CJK 0.7/字、其余 0.25/字符、向上取整）。两处仅用各自基准互锁，属数据/逻辑双轨，须归一。

**决策**：唯一实现归 `messages` 积木（L1）——`messages` 是消息领域的所有者，token 估算是消息/文本度量工具。消费方（compression L2、tools L2）均可向下引用 L1，无分层障碍。

## 修改要求

1. `v2/narnat_agent/messages/` 新增 `tokens.py`：`estimate_text_tokens(text) -> int` 与 `estimate_message_tokens(msg) -> int`——从现有实现**逐字搬运**（系数与取整语义完全一致），中文 docstring 注明基准来源（`v2/tests/baseline/data/token_estimate.json` 与 `compressor.json` 双向锁定）。
2. `v2/narnat_agent/compression/compressor.py`：删除本地副本，改为 `from ..messages.tokens import ...`；coordinator.py 等如经 compressor 中转则保持引用路径不变。
3. `v2/narnat_agent/tools/token_estimate.py`：删除本地实现，改为**薄转发** re-export（`from ..messages.tokens import estimate_text_tokens, estimate_message_tokens`），保持 tools 族内部既有 import 路径不变（消费方：tools/file/read.py、tools/registry.py、tools/remote/common.py、tools/shell/executor.py、tools/__init__.py）。
4. 测试调整：compression 的测试若有引用 `compressor.estimate_*` 的，改为引用新位置（或保留转发路径不改）；为 `messages/tokens.py` 补最小单测（系数矩阵）；确保两侧既有基准对照仍然生效。
5. 不得改动其他积木与文件。
